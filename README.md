# ПОЛКА — Доска бесплатных объявлений и маркетплейс безопасных сделок

> **«ПОЛКА — всё по полочкам»**  
> Современная городская витрина объявлений и маркетплейс с надежной защитой каждой сделки (Escrow 100%), быстрой доставкой по всей России и мгновенной автовыдачей цифровых товаров.

---

## ✨ Ключевые возможности платформы

### 1. Витрина и поиск лотов
* **Умная поисковая строка** с автодополнением и мгновенной очисткой.
* **Быстрые интерактивные фильтры-чипсы:**
  * 🛡️ *Полка Защита (Escrow)*
  * ⚡ *Моментальная автовыдача*
  * 🎁 *Даром / Бесплатно (0 ₽)*
  * 🔥 *VIP лоты*
  * ⭐ *Топ продавцы (4.95+)*
* **Переключатель витрины:** переключение между режимами **«Крупная сетка»** (плитка с фото) и **«Компактный список»** (высокая плотность).
* **Селектор городов и станций метро** для локальных покупок.
* **Интерактивные фотокарточки** с переключением фото наведением курсора.

### 2. Полка Защита (Безопасная сделка Escrow 100%)
* Средства покупателя надежно замораживаются на защищенном банковском счете на время доставки и проверки.
* Продавец видит подтверждение оплаты и отправляет лот (или система автоматически выдает ключ в чат).
* У покупателя есть до 24 часов на личный осмотр и проверку.
* Только после согласия покупателя средства переводятся продавцу.
* Встроенная служба честного арбитража прямо в карточке заказа.

### 3. Защита продавцов и анти-спам
* **Маскировка номера телефона:** защита от спам-парсеров и ботов (показ реального номера только по клику живого пользователя).
* Проверка документов продавцов (Госуслуги, паспорт).

### 4. Встроенный чат
* Диалог покупателя и продавца с контекстом конкретного лота в шапке.
* Быстрые подсказки-ответы (*«Лот ещё на Полке?»*, *«Возможен ли торг?»*, *«Отправите сегодня?»*).
* Умные автоматические ответы продавца в демо-режиме.

### 5. Личный кабинет и уведомления
* Размещение лотов бесплатно за 1 минуту с мгновенной публикацией.
* Управление активными объявлениями («На Полке»).
* Баланс кошелька и безопасный счет эскроу-сделок.
* Центр уведомлений (колокольчик) со статусами сделок и заказов.

## 🎨 Дизайн-система «Нео-Витрина»
* **Палитра:** Глубокий графит/индиго (`#0b0f19` / `#151d2e`), теплый янтарный акцент (`#f59e0b`), изумрудный цвет безопасности (`#10b981`), молочный светлый фон (`#fcfbf9`).
* **Темизация:** Полноценная поддержка **Светлой** и **Тёмной** темы с сохранением выбора пользователя.
* **Mobile-First:** Нижний навигационный бар для комфортной работы со смартфонов.

## 🚀 Быстрый старт на компьютере

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки
npm run dev

# 3. Сборка продакшен-бандла
npm run build
```

Сервер запустится по адресу: `http://localhost:3000`.
