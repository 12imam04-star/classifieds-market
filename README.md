# AvitoX — Современная Доска Бесплатных Объявлений

Современная высоконагруженная доска объявлений и маркетплейс, объединяющая архитектурные и визуальные преимущества **Авито (Avito.ru)**, **Playerok (Playerok.com)** и **GGsel (GGsel.net)**.

---

## 📊 Анализ стилей и UX сайтов-референсов

### 1. Avito.ru (Авито)
* **Визуальный стиль:** Чистый, нейтральный, белый фон, модульная сетка карточек, узнаваемая цветовая айдентика (4 фирменных цветных круга, синий, зеленый и фиолетовый акценты).
* **Ключевой UX:**
  * Умная строка поиска с подсказками и селектором городов/метро.
  * Интерактивная галерея на карточке: переключение фото точками при наведении курсора без перехода на страницу.
  * Детальный сайдбар фильтров (диапазон цен, состояние: новое/б-у, город, специфические параметры).
  * «Авито Доставка» — встроенная безопасная сделка с проверкой в ПВЗ.
  * Анти-парсинг защита номеров телефона (показ по клику).

### 2. Playerok.com (Плеерок)
* **Визуальный стиль:** Трендовый темный / неоновый геймерский дизайн, крупные скругления (`rounded-2xl`, `rounded-3xl`), плавные микровзаимодействия, ориентация на мобильный трафик (Mobile-first).
* **Ключевой UX:**
  * **Escrow-система:** Деньги покупателя надежно замораживаются на платформе. Продавец получает выплату только после проверки и подтверждения покупателем.
  * Встроенный диалог сделки с пошаговыми статусами («Оплачено» → «Передано» → «Проверено» → «Завершено»).
  * Механизм быстрого открытия спора (Арбитраж) прямо в карточке заказа.
  * Яркие плашки «Автовыдача», «VIP», «Срочно».

### 3. GGsel.net (ГГсел)
* **Визуальный стиль:** Высококонверсионный маркетплейс цифровых товаров и услуг, акцент на контрастные кнопки действий, плотное отображение каталога.
* **Ключевой UX:**
  * Быстрая покупка в 1 клик с выбором платежного метода (СБП 0%, банковские карты МИР/Visa, T-Pay).
  * Высокая прозрачность продавца: общее число продаж, процент довольных клиентов, средняя скорость ответа.
  * Четкое разграничение на мгновенную автовыдачу (ключи, коды) и ручную передачу.

## 🚀 Как запустить проект локально

```bash
# 1. Установка зависимостей (если не установлены)
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Сборка для продакшена
npm run build
```

Проект запустится на `http://localhost:3000`.

## 🔒 Сохранение в закрытый репозиторий GitHub (Private Repo)

Репозиторий уже инициализирован локально (`git init`) и готов к отправке.

### Шаг 1. Создайте закрытый репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Укажите название репозитория (например, `avitox-classifieds` или `doska-obyavleniy`).
3. **Обязательно выберите опцию: Private (Закрытый)**.
4. Снимите галочки с «Add a README file» и «Add .gitignore» (они уже есть в проекте).
5. Нажмите кнопку **Create repository**.

### Шаг 2. Подключите удаленный репозиторий и сделайте push:
В терминале внутри папки проекта выполните:

```bash
# Добавьте адрес вашего созданного закрытого репозитория
git remote add origin https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git

# Отправьте ветку main в закрытый репозиторий
git branch -M main
git push -u origin main
```
